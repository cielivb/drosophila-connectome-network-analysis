Connectivity data for the FlyWire Connectome release


Data developed for: codex.flywire.ai

Data origin: https://zenodo.org/records/10676866 (https://doi.org/10.5281/zenodo.10676866)

Associated publication: https://www.nature.com/articles/s41586-024-07558-y

Data License: Creative Commons Attribution 4.0 International (https://creativecommons.org/licenses/by/4.0/)




File : proofread_connections_783.feather

16,847,997 rows

Columns (descriptions taken from zenodo):

pre_pt_root_id: (int64) presynaptic neuron ID 
post_pt_root_id: (int64) postsynaptic neuron ID
neuropil: (string) neuropil name. Symmetric neuropils contain a hemisphere annotation after '_'. E.g., ME_L is the medulla in the left hemisphere. For mapping long names, see Ext. Data Fig. 1 or https://codex.flywire.ai/app/neuropils
syn_count: (int64) number of synapses between these two neurons in this neuropil
gaba_avg: (double) average probability across the synapses for neurotransmitter=GABA
ach_avg: (double) average probability across the synapses for neurotransmitter=Acetylcholine
glut_avg: (double) average probability across the synapses for neurotransmitter=Glutamate
oct_avg: (double) average probability across the synapses for neurotransmitter=Octopamine
ser_avg: (double) average probability across the synapses for neurotransmitter=Serotonin
da_avg: (double) average probability across the synapses for neurotransmitter=Dopamine
